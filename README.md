# 芙蓉历 · 功能与用法

芙蓉历是一款安卓日历 App（木芙蓉主题），包名 `app.furong.calendar`。
本文只说明**功能与用法**，覆盖当前 0.1.59 的全部功能。

所有设置与入口都集中在首页右上角的 **「说明/反馈」** 菜单里；少数高频操作在首页直接有按钮。

---

## 零、首次安装（新朋友先看这里）

**从 GitHub 下载安装**
- 打开最新版下载页：https://github.com/Forestmorning/furong-calendar/releases
- 在页面最下方「Assets」里点 `furong-calendar-….-release.apk` 下载；或把朋友分享来的安装直链直接贴到手机浏览器。
- 安卓 8 及以上**首次**从浏览器安装，会提示「允许该浏览器安装未知应用」，按引导开一次即可（以后这台手机从浏览器安装都免问）。
- **App 内自动更新也要授权一次**：首次点「立即更新」时，App 会跳到「安装未知应用」设置页，把「芙蓉历」设为允许即可（只需一次）。没开之前点更新只会跳设置、不会开始下载，属正常现象。
- 装好后**打开一次 App**，以后升级全自动：App 自己检查、下载并提示安装，**同一把正式签名覆盖，日程和布局数据不丢**。

**在 App 里分享给新朋友**
- 已装好的朋友点「说明/反馈 → 分享给朋友（安装链接）」，可一键把当前最新版安装直链复制并发到微信 / QQ / 邮件，链接不会过期。

> 国内访问 GitHub 偶尔偏慢；若打不开，让朋友找你要 APK 文件用微信/邮件传过去安装，拿到的是同一个安装包，效果完全一样。

**已装过 0.1.57 / 0.1.58 的朋友请注意**：那两版把更新地址写死在 `raw.githubusercontent.com`，国内手机网络下会被干扰，导致点「检查更新」提示「无法连接更新服务器」、收不到自动更新。请**手动下载安装一次 0.1.59**（就是上面那个下载页，或让朋友用 App 内「分享给朋友（安装链接）」发链接给你），覆盖安装即可，日程和布局数据不丢；装好后以后升级就恢复正常、全自动了。

## 一、首页与日历视图

**功能**
- 木芙蓉主题主界面：花叶装饰，标题与日期使用「霞鹜文楷」字体。
- 三种视图：**三天 / 一周 / 整月**，顶部日期条今天固定贴左。
- 整月视图可前后翻月；**有日程的日子显示瓢虫标记**，跨天日程在首尾两天各显示一个瓢虫、并用虚线连接。
- 行程列表按「所选的某一天」显示当天日程（搜索模式除外）。
- **竖屏锁定**：App 始终竖向，不随手机旋转。

**用法**
- 首页顶部三个标签「三天 / 一周 / 整月」直接切换视图。
- 整月视图点「‹ / ›」翻月；点某一天格跳转并查看那天日程。
- 点「今天」按钮回到今天。

## 二、记日程与管理

**功能**
- 新增日程：事项标题、开始日期、开始时间、结束时间、是否全天、重复规则、提醒设置。
- 重复支持：**不重复 / 每天 / 每周 / 每月 / 每年**。
- 编辑与删除：点已有日程弹出操作菜单（重复日程可「整组」或「单次」处理）。
- 按标题搜索日程。
- 跨天日程在涉及的多天里都可见，并钳到对应日期显示。

**用法**
- 首页点「**＋**」按钮 → 填写表单 → 保存。
- 点列表里的某条日程 → 选「编辑日程 / 删除日程」。重复日程会多一个「整组」选项。
- 想搜某条：首页「说明/反馈 → 搜索日程」，输入标题关键字。

> 示例（非真实数据）：「周五 19:30 家庭聚餐」「下周一 09:00 复诊」，填好后即出现在对应日期下。

## 三、提醒

**功能**
- 默认多级提醒：**提前一天（静音低优先级提示）→ 提前一小时（震动）→ 提前半小时（声音）→ 提前十分钟（响一次、连震三下）→ 正点（声音 + 较长震动，可用系统闹钟保障准时）**。
- 单条日程可在表单里设为「跟随全局 / 不提醒 / 仅提前一小时 / 仅半小时 / 仅十分钟 / 仅到点」其中一种。
- 全局提醒声一次设置、对所有日程和所有提醒阶段统一生效（共 14 种声音可选）。
- 到点通知可「完成」或「稍后提醒」。
- 手机重启、时区/系统时间变更、App 升级后，提醒会自动重排。

**用法**
- 新增/编辑日程时，在表单的「提醒」项里选择该条的强度。
- 统一查看与调整：在提醒设置里可切换**提醒声**、开/关**声音总开关**与**震动总开关**、查看通知与准时闹钟权限状态，并点「**测试到点声音和震动**」试听。
- Android 12 及以上若未授予「闹钟和提醒」权限，系统可能延迟提醒；保存日程时会提示前往授权。

## 四、AI 记日程（DeepSeek）

**功能**
- 用 DeepSeek 把自然语言解析成日程（例如「后天下午三点去公园拍照」）。
- 密钥用 Android Keystore 加密后只存在本机，**备份时不包含密钥**。
- 首次使用若未设置密钥，首页顶部会出现**橙色常驻横幅**提示：「未设置 DeepSeek API Key，需在 说明/反馈 → DeepSeek API Key 设置 填写后才能使用」，点横幅直接跳到设置页（不再一闪而过）。

**用法**
- 首页顶部语音（🎙）按钮点一下打开输入框：
  - 直接**输入文字**描述日程；
  - 或点框里的「🎤 语音输入」，唤起你当前输入法的语音转文字；
  - 识别/输入完成后发送给 DeepSeek 解析，**结果仍需你确认才保存**。
- 填密钥：首页「说明/反馈 → DeepSeek API Key 设置」，粘贴官方 API Key 保存（回读一致才算成功）。
- 每台设备各自填自己的 Key；换机或清除 Key 后需重新填写。

## 五、图片识别日程（离线 OCR）

**功能**
- 用设备端 ML Kit 中文 OCR 识别图片里的日程文字，再交给 DeepSeek 解析成日程。
- **完全离线识别**，不依赖网络、也不需要任何密钥；只有最后解析那一步才用到 DeepSeek（若已设置 Key）。

**用法**
- 方式一（推荐）：在微信里把含日程安排的**截图/照片「分享」给「芙蓉历」**（系统分享面板选本 App），自动进入识别。
- 方式二：在首页 AI 输入框点「图片」按钮，从本机选一张图。
- 识别出的文字会先展示，确认后保存为日程。

## 六、天气（Open-Meteo）

**功能**
- 首页花朵右上角的天气卡片：显示当天雨况与最高/最低温。
- 数据源为 Open-Meteo 的免费接口，**无需申请 Key、无需配置**。
- 每日早上 6 点尝试刷新；进入 App 时至多每日补一次定位。后台只用最近一次前台位置，不申请后台定位。

**用法**
- 首次使用点一下天气卡片，按提示允许定位即可。
- 接口不可用时保留上次成功的结果，不会空白。
- 天气坐标只存本机，并从系统备份/换机迁移中排除。

## 七、首页 Logo 与布局自定义

**功能**
- 可手动摆放主花、天气图标、当天日程文字框的位置与大小。
- 日程框还能单独调**宽度**与**高度**并保存。
- 支持「布局码」：把当前布局导出为一串字符，或粘入他人分享的布局码一键套用。
- 字体与主题自带，无需额外设置。

**用法**
- 摆放：首页「说明/反馈 → 调整首页 Logo」，拖动各元素、用滑杆调大小，满意后保存。
- 套用布局码：首页「说明/反馈 → 导入 Logo 布局」，粘贴形如 `4v …` 的全量布局码预览后保存。
- 想还原：「说明/反馈 → 恢复默认布局」（会弹二次确认）。
- 临时看花：首页「说明/反馈 → 花色预览滑杆」，拖动可预览任意时点的木芙蓉主花（**不动系统时间**），再选「退出花色预览」恢复实时。

**用法**
- 首页「说明/反馈 → 进入屏保」。

## 九、自动在线更新

**功能**
- 打开 App 会**静默检查更新**（24 小时内最多一次），发现新版本弹窗：「立即更新 / 稍后 / 跳过此版本」。
- 下载完成后自动调起系统安装，**同一把正式签名覆盖安装，你的日程和布局数据不丢**。
- **0.1.59 起更新源改为国内手机可直连的地址**：主用 GitHub Release 的固定永久链接（`github.com/…/releases/latest/download/update.json`），另有 jsDelivr 与 raw 两个备用地址依次兜底；主地址失败会自动换下一个，不会再出现「无法连接更新服务器」。开发者发新版时把这个 `update.json` 一并放进最新 Release，App 里的地址就再也不用改。

**用法**
- 自动：什么都不用做，有新版时按提示点「立即更新」即可。
- 手动：首页「说明/反馈 → 检查更新」可随时主动检查。
- 首次更新若跳到「安装未知应用」设置页，把「芙蓉历」允许一次即可；之后不再询问。
- 下载完成后系统会弹一次安装确认（安卓安全机制，App 无法静默安装），点「安装」即完成覆盖升级。

## 十、分享安装链接给朋友

**功能**
- 一键把「当前版本的安装包直链」复制并分享出去，朋友点链接即可下载安装。
- 链接由 App 用自身版本号自动拼接，所以 App 自更新后，你分享出去的永远是当时最新的安装包，**不会过期**。

**用法**
- 首页「说明/反馈 → 分享给朋友（安装链接）」：
  - 链接会复制到剪贴板，并弹出系统分享面板，直接选**微信 / QQ / 邮件**发给朋友；
  - 若手机没装可分享的 App，会提示「链接已复制，去粘贴给朋友即可」。

## 十一、日程备份

**功能**
- 把全部日程导出为一个 JSON 备份文件；也能从备份文件合并恢复（按稳定 ID 去重，不会重复）。

**用法**
- 首页「说明/反馈 → 日程备份 → 导出备份文件」保存；
- 换机或重装前，先「从备份恢复（合并导入）」把日程拿回来。

## 十二、反馈与帮助

**功能**
- 「说明/反馈」菜单含：功能说明与使用方法、搜索日程、日程备份、评分/吐槽/建议、查看已收集反馈、导出反馈汇总、邮件反馈给开发者、调整首页 Logo、导入 Logo 布局、DeepSeek API Key 设置、恢复默认布局、进入屏保、花色预览滑杆、检查更新、分享给朋友（安装链接）。
- 评分吐槽建议：给当前版本打 1–5 星、选类别、填内容，记录存本机。
- 反馈内容**只包含**评分、类别、意见文字、提交时间、版本、设备型号与 Android 版本；**不包含你的日程和 API Key**。

**用法**
- 想提意见：首页「说明/反馈 → 评分、吐槽或建议」。
- 想发给开发者：选「邮件反馈给开发者」（预填收件人，需本机配邮件 App 手动发），或「导出反馈汇总」生成 JSON 自行发送。
- 看操作说明：首页「说明/反馈 → 功能说明与使用方法」。

**用法**
